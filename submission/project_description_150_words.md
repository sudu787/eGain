# Submission description (130 words)

During an outage, residents need reliable safety guidance and a clear next step. GridGuide is an eGain customer-service agent for a fictional electric utility. It answers preparedness questions from source-linked content, prioritizes urgent electrical hazards, and can create a persistent demo outage report through a connected API action. The API returns a reference and clearly says the record stays in the demo database; it is not sent to a utility. GridGuide collects only a broad demonstration service area and issue category, never an account number or medical details. It does not claim live outage status or restoration estimates. For non-urgent follow-up, it presents two fictional contact options; for immediate danger, it directs residents to local emergency services. GridGuide demonstrates safety-first triage paired with a bounded service action and clear limits.
