# Judging criteria mapping

| Criterion | Demonstrated feature | Evidence to capture |
|---|---|---|
| Customer and business value (25) | Fast path from outage question to report, with safety needs prioritized | Demo shows routine user task plus urgent branch; describe value as a hypothesis, not measured outcome |
| Functionality and reliability (25) | Grounded knowledge, bounded API inputs, idempotent receipts, explicit failure path | Test report with actual local and eGain results; published link |
| Effective use of eGain (20) | Verified: knowledge source, reviewed intents, Custom API action, and agent demo page. Pre-chat and intent-connected process workflow are not yet evidenced. | Capture account evidence and test the connected workflow before claiming those capabilities. |
| Creativity and CX (15) | Impact-aware triage, minimal data collection, coherent safety-first routing | Demo contrasts urgent safety route with normal reporting |
| Action and good judgment (25) | Persistent demo action has returned receipts; safety and live-status boundaries are specified. The ordinary report request currently bypasses confirmation, so the action workflow fails this safeguard until corrected. | Fix and retest the confirmation/decline branch before showing the action as safe; also show refusal to estimate restoration. |
| Demo storytelling (15) | 60-second knowledge + workflow + report action + distinguishing safety triage | Final video URL and timed script |

**Scoring note:** the official rules page lists 125 total points. Its displayed category values sum to 125 when Action & Good Judgment is counted as 25 points and Demo Video and Storytelling as 15 points.
